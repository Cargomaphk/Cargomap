貨機裝載系統 (Air Cargo Loading & ULD/PMC Tracking System)
================================================================================

【系統簡介】
「貨機裝載系統」是一款專為航空貨運機坪與裝卸作業設計的行動端網頁應用程式。
採用單一 HTML 檔案架構，無需架設後端伺服器，開啟瀏覽器即可使用，並針對手機觸控
與戶外作業環境（如防誤觸確認、離線暫存補傳）進行深度優化。

本系統整合了「貨板抄板追蹤」、「智慧艙單解析」、「多機型艙位平面圖」、「多人
即時同步」與「三重數據冗餘保護」，協助裝載人員快速核對 ULD/PMC 貨板位置並生成
關艙交接紀錄。

--------------------------------------------------------------------------------
【核心功能】
--------------------------------------------------------------------------------

1. 貨板抄板與機身小地圖導航 (PMC Staging & Minimap)
   • 分區抄板管理：涵蓋左/右紅白格 (L3-R3)、左/右翼 (C-Z)、左後 (11-31) 及
     右後 (51-71) 區域，支援點擊標記「已裝載（灰底）」與折疊收納。
   • 智慧邊框辨識：
     - 藍色 / 綠色邊框：依輸入號碼首位數字自動區分（0-4 藍框、5-9 綠框）。
     - 紫色邊框：與艙單資料成功配對，並於右上角顯示對應艙位代號。
     - 紅色邊框：經由拖曳對調過位置的貨板標記。
   • 互動式小地圖：即時顯示全場已抄入與已裝載板數，點擊任一行可一鍵跳轉並閃爍
     定位目標區域。
   • 快速搜尋定位：輸入完整號碼或局部數字即可高亮顯示並自動展開所屬區塊。

2. 智慧艙單解析與尾碼碰撞偵測 (Manifest Parsing)
   • 一鍵貼上與 AI 輔助：內建 AI 整理指令複製功能，貼上包含「艙位」與「PMC/ULD
     號碼」的文字後即自動解析並綁定抄板位置，支援自動過濾多餘板位前綴。
   • 兩階段精確比對：優先比對完整 ULD 編碼，其次比對 5 位數簡碼。
   • 5 位數尾碼重複警告：若艙單中出現相同 5 位數但不同前綴的貨櫃/貨板，系統會
     自動標示「⚠️」並強制顯示完整編號，避免錯裝。
   • 缺板即時統計：動態計算艙單總數與尚未尋獲的 PMC 數量。

3. 多機型平面圖與智能動態佈局 (Aircraft Hold Layouts)
   • 支援機型：內建 B744 (74Y)、B748 (74N)、A330 (333)、B767 (76F)、B77F (77F)
     的主艙 (MAIN) 與下艙 (LOWER) 平面配置，自動標示艙門位置（橘底）與 20 呎
     長板（跨兩格顯示）。
   • 智能適配模式：根據貼上的艙單板位自動判斷機型特徵並動態生成雙欄平面圖。
   • 防誤觸二次確認：點擊平面圖板位時彈出大型確認視窗，顯示板位、貨板號碼與抄板
     位置，有效防止雨天或戴手套操作時誤觸相鄰板位。
   • 平面圖拖曳調位與順序追蹤：支援在平面圖上直接拖曳對調兩個板位（同步更新艙單
     並標示紅框），自動記錄裝載順序編號，並可隨時切換「完整顯示／簡化顯示」。

4. 多人即時同步與離線自動補傳 (Supabase Real-time Sync)
   • 主控者 (Host) 與閱讀者 (Viewer) 模式：
     - 主控者輸入房間號碼 (Room ID) 與配對密碼 (Passcode) 建立房間，可即時查看
       在線閱讀人數並擁有主控權心跳保護。
     - 閱讀者登入後進入唯讀同步模式，當主控者標記新裝載板位時，閱讀者畫面會自動
       切換至對應機型並以黃色閃爍提示最新裝載位置。
   • 斷網暫存與自動補傳：網路中斷時變更會安全暫存於本機並顯示離線狀態，待網路
     恢復後自動重新連線並補傳最新數據。

5. 三重數據冗餘保險箱 (Triple-Layer Data Protection)
   • 三層同步寫入：主存儲 (localStorage) + 校驗碼鏡像備份 + IndexedDB 離線資料庫，
     開啟頁面時自動檢測並修復異常清空的資料。
   • 時間點快照與檔案備份：於開房同步前、清除數據前及定時檢查點自動建立最多 10 筆
     歷史快照，亦支援手動建立備份及 JSON 檔案匯出／匯入還原。

6. 關艙交接摘要與截圖匯出 (Handover Summary & Screenshot)
   • 一鍵生成交接明細：自動彙整艙單總數、已裝載順序明細、未裝載艙位及人工調位
     異動紀錄，支援一鍵複製文字。
   • 自動生成艙位截圖：將當前機型平面圖與裝載統計渲染為高解析度 PNG 圖片，手機端
     可直接長按儲存或透過系統分享面板傳送。

--------------------------------------------------------------------------------
【快速使用指南】
--------------------------------------------------------------------------------

1. 啟動方式：
   - 直接於瀏覽器開啟主程式 HTML 檔案，或透過 GitHub Pages 部署後以手機開啟。
   - 若需啟用雲端同步功能，請於程式碼內設定您的 SUPABASE_URL 與 SUPABASE_ANON_KEY。

2. 操作流程：
   步驟一：選擇「登入抄板」（主控者/單機作業）或輸入房間號碼與密碼「登入閱讀」。
   步驟二：於「抄板」頁面輸入現場貨板號碼，或點擊「艙單」貼上艙單文字進行配對。
   步驟三：切換至對應機型（如 B744、B77F）或「智能」頁面，點擊板位確認裝載進度。
   步驟四：如需與同事共享進度，點擊「同步」開啟房間；作業完成後可於裝載順序區
           點擊「匯出摘要」保存文字與平面圖截圖。

--------------------------------------------------------------------------------
【技術架構】
--------------------------------------------------------------------------------
• 前端核心：原生 HTML5 / CSS3 / Vanilla JavaScript (ES6+)，單一檔案零建置依賴
• 雲端同步：Supabase (PostgreSQL RPC + Realtime Broadcast / Presence)
• 離線存儲：Web Storage API (localStorage 雙重鏡像) + IndexedDB
• 截圖引擎：html2canvas (附原生 HTML5 Canvas 離線備援繪圖)
